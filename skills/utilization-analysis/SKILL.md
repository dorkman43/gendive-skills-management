# 센터별 생산성·가동률·베이 회전율

센터마다 정비 인력과 설비(리프트)를 얼마나 쓰고 있는지, 일한 시간이 얼마나 돈이 되는지, 차가 어디서 기다리는지를 보여줍니다. 가동률·작업효율 정의는 회사마다 달라서 **분자·분모를 항상 같이 적습니다.**

## 이럴 때 쓴다
- "센터별 가동률과 효율을 비교해줘"
- "A센터는 늘 바쁜데 매출이 안 따라와. 어디가 문제야?"
- "입고부터 출고까지 평균 며칠(몇 시간) 걸리는지, 기다리는 시간이 얼마나 되는지 알고 싶어"
- "베이(리프트) 몇 개가 적당한지 감을 잡고 싶어"

## 준비할 데이터
- 필수(센터·월별): 정비 인원, 가용시간(근무 가능한 시간), 실작업시간(차에 실제로 손댄 시간), 청구 공임시간(고객·보증·보험에 청구한 시간), 베이 수, 입고대수, 영업일수
- 있으면 좋은 것: 작업지시서별 입고·작업시작·작업완료·출고 시각, 재수리(같은 문제로 다시 온 차) 표시
- 개인정보(고객명, 차량번호)가 있으면 `data-masking`부터 합니다. 표가 지저분하면 `excel-cleanup`을 먼저 쓰세요.

## 시작 전 확인
1. 회사에 가동률·효율·재수리율의 **자체 정의**가 있나요? 있으면 그것을 쓰고, 없으면 아래 정의를 씁니다.
2. 가용시간에 휴가·교육·점심 시간이 들어 있나요? 실작업시간은 어디서 가져온 값인가요(작업지시서 타각, 정비사 보고 등)?
3. 영업일은 월~금인가요, 토요일도 영업하나요? 재수리는 최종 정비일로부터 며칠 안에 같은 부위로 다시 온 것을 말하나요?

## 절차
1. **자료 점검**: 센터·월 행 수, 빈칸, 분모가 0인 행을 확인합니다. 빈칸은 0이 아닙니다. 해당 행을 제외하고 알립니다.
2. **합계로 계산**: 월별 비율을 단순 평균하지 않고 기간 내 시간 합계끼리 나눕니다(가중). 센터별 표를 만들어 보여주고 확인받습니다.
3. **판정**: 아래 기준표로 센터별 상태를 표시합니다.
4. **4분면 배치**: 가동률(세로) × 작업효율(가로)로 센터를 나눕니다. 그림은 `chart-dashboard`로 만듭니다.
5. **작업지시서 분석**(있을 때): 체류시간과 대기 비중, 재수리율을 센터별로 계산합니다. 출고시각이 비어 있는 건(아직 출고 전일 수 있음)은 제외하고 건수를 적습니다. 표본 건수가 적으면 "표본이 적어 참고용"이라고 밝힙니다.
6. **개선 포인트**: 센터마다 "확인할 것" 2~3개로 정리합니다. 원인은 데이터로 확인되지 않으면 쓰지 않고 확인할 사람·자료를 제안합니다. 실행계획으로 이어가려면 `action-plan`을 씁니다.

## 지표 정의 (이 스킬에서 쓰는 정의)
국내 공식 정의는 확인하지 못했습니다. 아래는 해외 자동차 딜러 서비스센터에서 쓰는 방식을 번역한 것이고, 베이 회전율은 해외 정의도 없어 **이 스킬의 작업 정의**입니다.

| 지표 | 계산식 |
|---|---|
| 가동률 | 실작업시간 ÷ 가용시간 |
| 작업효율 | 청구 공임시간 ÷ 실작업시간 |
| 종합생산성 | 청구 공임시간 ÷ 가용시간 (= 가동률 × 작업효율) |
| 베이 회전율 | 입고대수 ÷ 베이 수 ÷ 영업일수 (하루 베이 한 개당 몇 대) |
| 체류시간 | 출고시각 - 입고시각 |
| 대기시간 | (작업시작 - 입고) + (출고 - 작업완료) |
| 대기 비중 | 대기시간 합계 ÷ 체류시간 합계 |
| 재수리율 | 재수리 건수 ÷ 전체 작업 건수 (집계 기간을 정해 적음) |

## 판정 기준
| 항목 | 기준 | 근거 |
|---|---|---|
| 가동률 | 85% 초과 과부하 의심 / 70~85% 적정 / 70% 미만 여유 | 이 스킬의 출발값 (회사 기준으로 조정). 해외 딜러 자료는 목표를 85~95%로 소개하지만 정비사 과부하·품질 위험을 함께 보려고 85% 초과를 따로 표시함 |
| 작업효율 | 100% 미만이면 일한 시간보다 청구가 적음 | 이 스킬의 출발값. 해외 딜러 자료는 110~125%를 참고치로 소개 (회사 기준으로 조정) |
| 센터 간 불균형 | 가동률 차이가 30%p 초과 | 이 스킬의 출발값 (회사 기준으로 조정) |
| 병목 의심 | 체류시간 중 대기 비중 40% 초과 | 이 스킬의 출발값 (회사 기준으로 조정) |
| 4분면 | 가동률 70% 이상/미만 × 작업효율 100% 이상/미만 | 이 스킬의 출발값 (회사 기준으로 조정) |

4분면 해석 틀: 가동률 높고 효율 낮음 = 바쁜데 청구가 적음(재작업, 기록 누락, 숙련도, 표준시간 설정 확인). 가동률 낮고 효율 높음 = 일 자체가 부족하거나 대기로 못 일함(입고량, 부품 대기 확인). 둘 다 높음 = 양호하되 과부하 주의. 둘 다 낮음 = 우선 점검.

## 결과물
- 엑셀: `센터별지표`(지표마다 분자·분모 열 포함), `월별추이`, `작업지시서분석`, `확인필요` 시트
- 4분면 그림, 센터별 개선 포인트 표(센터 / 상태 / 확인할 것 / 확인할 사람)
- 개조식 요약 틀: □ 결론(과부하·여유·대기가 큰 센터) / ○ 센터 간 차이(%p) / ○ 병목 구간 / ※ 정의와 기간
- 보고 전 숫자 점검은 `report-qa`를 이어 쓰세요.

## 하지 말 것
- 지표를 쓸 때 분자·분모를 빼지 않습니다. "해외 딜러 업계 방식" 또는 "이 스킬의 정의"라고 밝힙니다.
- 월별 비율을 단순 평균하지 않습니다.
- 빈 시각·빈 시간을 0이나 임의 시각으로 채우지 않습니다.
- 가동률이 낮다고 인력이 남는다고, 효율이 낮다고 정비사 탓이라고 단정하지 않습니다. 원인은 확인 필요입니다.
- 정비사 개인 이름 대신 센터·직책 단위로 정리합니다.

## 국내 기준 메모
- 서비스센터 운영 지표(가동률, 작업효율, 종합생산성, 베이 회전율, 재수리율)의 국내 공식·협회 정의는 확인하지 못했습니다(확인일 2026-10-15). 가동률·효율 정의는 해외 딜러 컨설팅 자료의 용어를 번역한 것이며 자료마다 정의가 달라 분자·분모를 적게 했습니다.
- 재수리 기간을 정할 때 참고: 한국소비자원이 알리는 재발 하자 무상수리 기준(정비 잘못으로 같은 부위가 재발하면 차령·주행거리에 따라 최종 정비일부터 90일 또는 31일 등)이 언론에 소개된 바 있으나(2차 보도) 지표의 공식 정의는 아닙니다.
